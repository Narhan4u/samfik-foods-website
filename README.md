# Samfik Foods Website

Website for **Samfik Foods**, authentic Nigerian food at Unit B4, Macclesfield Market Hall, Grosvenor Centre, Macclesfield, SK11 6AJ.

- Live site: https://samfikfoods.co.uk/
- Orders: WhatsApp / phone 07404 531445

It's a plain HTML, CSS and JavaScript site with no build step. Open `index.html` in a browser to preview it. It's published by GitHub Pages through `.github/workflows/pages.yml`.

**See [HANDOVER.md](HANDOVER.md)** for how to change prices and dishes, add photos, update hours and the phone number, and set up hosting and the domain.
